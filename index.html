My QA Workflow

A structured approach to manual testing.

I follow a simple testing workflow to move from understanding a feature to validating fixes and checking related areas.

01

Understand

Review the feature, expected behavior, user flow, and available requirements.

02

Design

Prepare relevant test scenarios, test cases, and required test data.

03

Execute

Perform the tests and compare actual application behavior with expected results.

04

Report

Document defects with clear reproduction steps, evidence, and expected behavior.

05

Retest

Verify resolved issues after fixes are provided by the development team.

06

Regression

Check related areas to make sure recent changes have not introduced new problems.
